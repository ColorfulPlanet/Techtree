# 3人パーティー隊列システム - プロトタイプ

2D見下ろし型アクションゲームの3人パーティー隊列システムのプロトタイプ実装です。

## 概要

HTML5 Canvas + JavaScriptで実装された、スマートフォン向けブラウザゲームです。
3人のキャラクター（A, B, C）が三角形の隊列を組んで移動し、1つのUIボタンで隊列のローテーションと間隔調整を行えます。

## 主な機能

### 1. 隊列システム
- 3人のキャラクターが三角形の隊列を維持
- 先頭1人、後衛2人の配置
- 隊列を保ったままパーティー全体が移動

### 2. 隊列ローテーション
- 画面右下の「隊列」ボタンをタップ
- 先頭キャラクターがA→B→C→Aと時計回りにローテーション
- 先頭キャラクターは金色の枠で強調表示

### 3. 隊列間隔調整
- 「隊列」ボタンを上下にスライド
- 上方向：隊列が広がる
- 下方向：隊列が狭まる
- 最小値（60px）から最大値（180px）の範囲で連続的に変化

### 4. タップ/スライド判定
- 移動量50px未満：タップ（隊列ローテーション）
- 移動量50px以上：スライド（隊列間隔変更）
- 誤判定を防ぐための閾値設定

## 操作方法

### パーティーの移動
- 画面内をクリック/タップ：目標地点に向かって移動

### 隊列操作
- 右下の「隊列」ボタンをタップ：先頭キャラクターをローテーション
- 「隊列」ボタンを上下にドラッグ：隊列間隔を調整

### UI表示
- 左上：デバッグ情報（先頭キャラ名、隊列間隔）
- 右側：隊列間隔ゲージ

## 設定パラメータ

各種パラメータは以下のファイルで調整できます：

### FormationManager（formation.js）
- `formationSpacingMin`: 隊列間隔の最小値（デフォルト: 60）
- `formationSpacingMax`: 隊列間隔の最大値（デフォルト: 180）
- `formationSpacing`: 隊列間隔の初期値（デフォルト: 100）
- `transitionDuration`: 隊列変更時の移動時間（デフォルト: 0.2秒）

### FormationInputHandler（input.js）
- `tapThreshold`: タップ判定の閾値（デフォルト: 50px）
- `slideSensitivity`: スライド感度（デフォルト: 0.5）

### Character（character.js）
- `radius`: キャラクターの描画サイズ（デフォルト: 20）
- `moveSpeed`: 移動の補間速度（デフォルト: 0.15）

### Game（game.js）
- `partyMoveSpeed`: パーティー全体の移動速度（デフォルト: 0.08）

## 設計思想

### データとロジックの分離
- パーティーメンバー管理（FormationManager）
- 隊列位置計算（FormationManager）
- タッチ入力処理（FormationInputHandler）
- UI表示（Game）

各システムが独立しており、将来的にPC版、コントローラー操作などへの拡張が容易です。

### 既存システムへの配慮
最小限の実装で隊列システムを実現し、他のゲームシステムとの統合を容易にします。

### プロトタイプ重視
- 操作感の確認を最優先
- 視覚的なフィードバックを重視
- パラメータ調整が容易な設計
